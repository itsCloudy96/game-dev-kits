# Star Forge

A small idle / clicker about minting stardust.

Tap the star, buy generators, and eventually collapse the forge for a permanent production bonus. Progress is saved in this browser only.

## Run it

- Open `index.html` or serve the folder.
- Controls: **click the star** or press **Space**. Buy generators on the right. Collapse unlocks at 1,000,000 stardust.

## What's inside

- `game.js` — the `GEN` table (name, base cost, rate), prestige, save/load. Change the table to rebalance the game.
- `index.html` — layout and the big star button.
- Save key: `cloudy-star-forge-v1`.
- `audio.js`, `boot.js`, `style.css`.

No accounts, no server, no third-party analytics.
