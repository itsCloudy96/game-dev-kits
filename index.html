FAQ

What are Cloudy Game Dev Kits?

Free, original, MIT-licensed starter games you can play in the browser, download as a zip, and extend with Cursor, Claude, or another coding assistant. There are 7 kits right now.

Do I need to sign up or pay?

No. The kits on this site are free. A future 'Pro kits' line may be paid — it is only a placeholder today, with nothing to buy.

Can I use these in my own game or jam?

Yes. They are MIT-licensed. Keep the license, and do not add trademarked or copyrighted assets if you publish.

What is in each zip?

The playable game, a README, Cursor rules, and a prompt pack with step-by-step ideas for vibe-coding new features.

How should I run a kit?

Open index.html, or serve the folder with a simple static server. Orbit Garden vendors Three.js so it can run offline; if a 3D canvas is blank from a file:// URL, use a local server.
